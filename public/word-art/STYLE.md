# 단어 그림 규격 (word art)

어휘 카드의 그림. **한 벌로 보여야 하므로 아래를 벗어나지 않는다.**
세션이 바뀌어도 그림이 흔들리지 않게 하려고 만든 파일이니, 새 배치를 그리기 전에 먼저 읽을 것.

## 형식
- `viewBox="0 0 80 80"`, `width/height` 80. 파일 하나에 단어 하나.
- 파일명은 로마자(`romanization`)를 그대로. 매핑은 `manifest.json`(한국어 → 파일명).
- `public/` 정적 파일이다. **JS 번들에 넣지 말 것** — 카드에서 `<img>`로 지연 로딩한다
  (어휘 예문 JSON 950KB가 번들을 통째로 끌고 갔던 전례가 `vocabulary-words.ts` 주석에 있다).
- 접근성: 루트에 `role="img"`와 한국어 `aria-label`.

## 그리는 법
- **path 4~8개.** 그 이상 필요하면 대상을 잘못 골랐거나 너무 자세히 그리는 것이다.
- **외곽선 없음.** 형태는 면으로만. 선은 손잡이·다리·김처럼 진짜 가는 것에만.
- **바닥 그림자 하나**로 통일: `<ellipse cx="40" cy="70" rx="20" ry="4" fill="#000" opacity=".07"/>`
  (넓은 물건은 rx만 24~26까지)
- 그림은 대략 y=14~66 사이를 채운다. 화면에서 84px로 뜬다.
- 하이라이트는 흰색 `opacity .18~.35` 면 하나까지. 그라디언트 쓰지 않는다.

## 시각 문법 — 같은 뜻은 같은 기호로
개별 단어를 그리는 게 아니라 **틀을 정하고 찍어낸다.**
- **숫자** = 초록 점을 그 수만큼. 2~5개는 한 줄, 6개 이상은 두 줄.
- **요일** = 달력 격자에서 해당 칸 하나만 코랄로.
- **달(月)** = 달력 표지에 숫자.
- **때(오늘·어제·내일)** = 달력에서 동그라미 친 날. 어제는 왼쪽, 내일은 오른쪽 칸.
- **아침·저녁·밤** = 수평선 위 해의 높이와 색(아침 노랑 위, 저녁 코랄 걸침, 밤 남색+달).
- **이동(가다·오다)** = 사람 + 노란 화살표.
- **행위(먹다·마시다)** = 얼굴 + 손에 든 도구.
- **말(말하다·묻다)** = 얼굴 + 말풍선.
- **사람 수** = 1명 사람 / 2명 친구 / 3명 가족(작은 것 하나 포함).

## 그리지 않는 것
- **머리로 하는 동사**(이해하다·기억하다·존경하다) — 그림 자리에 예문 두 개.
- **B1 이상 추상어**(서론·책무·패러다임) — 그림 자리에 한자 어근 패널.
- 억지로 그리면 뜻을 좁히거나 왜곡한다. 빈칸이 아니라 **다른 내용**을 넣는다.

## 신체 부위 (배치 2에서 추가)
- **몸 전체 부위**(손·발·머리·목·어깨·팔·다리·무릎·배·등·가슴) = **회갈 사람 틀 하나**(`#CFC7B6`) 위에 해당 부위만 코랄(`#D4705C`). 등은 뒤돌아선 같은 틀.
- **얼굴 부위**(눈·코·입·귀·이·혀·얼굴) = **얼굴 틀 하나**(피부색 원 + 회갈 이목구비) 위에 해당 부위만 코랄. 얼굴 자체는 틀 전체가 코랄 테두리.
- **손·발의 세부**(손가락·손목·발가락·발목) = 손/발 **클로즈업 틀** 위에 해당 부위만 코랄.
- 피부 = 팔 클로즈업에 살색 면 + 작은 코랄 점.
같은 틀을 쓰는 이유: 학습자가 "같은 그림에서 다른 데가 빨갛다"를 보고 부위를 비교하게 하려는 것.
- **단, 틀 그대로 두면 84px에서 전부 같은 그림으로 보인다** (2차 검수에서 지적됨). 부위 쪽으로 **1.7~2.4배 확대 크롭**해서 그 부위가 화면을 채우게 한다: `<g transform="translate(40 40) scale(s) translate(-cx -cy)">`. 얼굴 전체·몸 전체(얼굴·몸)만 크롭 없이.

## 파일명 충돌
로마자가 같은 단어가 있다(입/잎 = `ip`, 배 = belly/pear/boat, 눈 = eye/snow, 차 = tea/car, 이 = tooth/two/this).
- `manifest.json`은 **그린 단어만** 넣는다. 로마자가 같다고 자동으로 묶지 말 것 (잎이 입 그림을 가리켰던 적 있음).
- 두 번째 단어를 그릴 때는 파일명에 뜻을 붙인다: `ip-leaf.svg`, `bae-pear.svg`, `nun-snow.svg`, `cha-car.svg`.
