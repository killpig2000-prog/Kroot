# 단어 그림 규격 (word art)

어휘 카드의 그림. **한 벌로 보여야 하므로 아래를 벗어나지 않는다.**
세션이 바뀌어도 그림이 흔들리지 않게 하려고 만든 파일이니, 새 배치를 그리기 전에 먼저 읽을 것.

## 형식
- `viewBox="0 0 80 80"`, `width/height` 80. 파일 하나에 단어 하나.
- 파일명은 로마자(`romanization`)를 그대로. 매핑은 `manifest.json`(한국어 → 파일명).
- `public/` 정적 파일이다. **JS 번들에 넣지 말 것** — 카드에서 `<img>`로 지연 로딩한다
  (어휘 예문 JSON 950KB가 번들을 통째로 끌고 갔던 전례가 `vocabulary-words.ts` 주석에 있다).
- 접근성: 루트에 `role="img"`와 한국어 `aria-label`.

## 그리는 법
- **path 4~14개.** 사람 얼굴·인물은 14까지(눈썹·귀·머리 갈래 등 디테일이 들어가야 서로 구분됨) — 그 이상이면 대상을 잘못 골랐거나 너무 자세히 그리는 것이다.
- **외곽선 없음.** 형태는 면으로만. 선은 손잡이·다리·김처럼 진짜 가는 것에만.
- **바닥 그림자 하나**로 통일: `<ellipse cx="40" cy="70" rx="20" ry="4" fill="#000" opacity=".07"/>`
  (넓은 물건은 rx만 24~26까지)
- 그림은 대략 y=14~66 사이를 채운다. 화면에서 84px로 뜬다.
- 하이라이트는 흰색 `opacity .18~.35` 면 하나까지. 그라디언트 쓰지 않는다.

## 시각 문법 — 같은 뜻은 같은 기호로
개별 단어를 그리는 게 아니라 **틀을 정하고 찍어낸다.**
- **숫자** = 초록 점을 그 수만큼. 2~5개는 한 줄, 6개 이상은 두 줄.
- **요일** = 달력 격자에서 해당 칸 하나만 코랄로.
- **달(月)** = 달력 표지에 숫자.
- **때(오늘·어제·내일)** = 달력에서 동그라미 친 날. 어제는 왼쪽, 내일은 오른쪽 칸.
- **아침·저녁·밤** = 수평선 위 해의 높이와 색(아침 노랑 위, 저녁 코랄 걸침, 밤 남색+달).
- **이동(가다·오다)** = 사람 + 노란 화살표.
- **행위(먹다·마시다)** = 얼굴 + 손에 든 도구.
- **말(말하다·묻다)** = 얼굴 + 말풍선.
- **사람 수** = 1명 사람 / 2명 친구 / 3명 가족(작은 것 하나 포함).

## 그리지 않는 것
- **머리로 하는 동사**(이해하다·기억하다·존경하다) — 그림 자리에 예문 두 개.
- **B1 이상 추상어**(서론·책무·패러다임) — 그림 자리에 한자 어근 패널.
- 억지로 그리면 뜻을 좁히거나 왜곡한다. 빈칸이 아니라 **다른 내용**을 넣는다.

## 신체 부위 (배치 2 → 3차 수정)
- **그 자체로 형태가 있는 부위는 실물을 그린다**: 눈(눈꺼풀+홍채+속눈썹), 코, 입(입술), 귀, 이(어금니 하나), 혀(벌린 입 속 혀), 손, 발, 머리(옆얼굴+머리카락), 팔(굽힌 팔), 다리, 배(배꼽), 가슴. 사람 위에 점 찍지 말 것 — 사용자 지적 2회(겹친다 → 점으로만 표기).
- **위치로만 존재하는 부위**(목·어깨·무릎·등)만 **살색 사람 틀**을 부위 쪽으로 1.8~2.4배 확대 크롭하고 그 부위를 코랄로: `<g transform="translate(40 40) scale(s) translate(-cx -cy)">`. 회갈 마네킹 금지.
- **뼈·피·심장·눈물·땀처럼 몸을 벗어난 것**은 아이콘 하나로 그리지 말고 **장면으로** — 예: 심장은 혈관이 이어진 상태로, 눈물은 우는 얼굴 옆에 흐르는 물방울로, 목소리는 말하는 입 + 음파로.
- **손·발 세부**(손가락·손목·발가락·발목) = 손/발 실물 틀 위에 해당 부위만 코랄.
- 피부 = 팔 클로즈업에 살색 면 + 작은 코랄 점.

## 가족 호칭 (배치 3에서 추가)
- **"나" = 작은 초록 옷 사람, 부르는 상대 = 코랄 옷.** 형제자매·자녀처럼 상대가 작을 때는 큰 쪽이 초록(나), 작은 코랄이 상대.
- **성별 = 머리 모양** (짧은 갈색 = 남, 양옆으로 내려온 긴 머리 = 여). ♂/♀ 기호 쓰지 않는다.
- **나이 = 키**, 노인 = 흰 머리(할아버지는 지팡이, 할머니는 쪽).
- 형/오빠·누나/언니: 상대는 같고 **"나"의 머리 모양만** 다르다 — 한국어의 화자 성별 구분을 그림으로 옮긴 것.
- 삼촌/이모/고모 = 부모(초록 어른) 옆에 손 잡은 코랄 어른. 이모는 엄마(긴 머리) 옆, 고모는 아빠(짧은 머리) 옆.
- 부부(아내·남편) = 어른 둘 + 위에 작은 하트.

## 파일명 충돌
로마자가 같은 단어가 있다(입/잎 = `ip`, 배 = belly/pear/boat, 눈 = eye/snow, 차 = tea/car, 이 = tooth/two/this).
- `manifest.json`은 **그린 단어만** 넣는다. 로마자가 같다고 자동으로 묶지 말 것 (잎이 입 그림을 가리켰던 적 있음).
- 두 번째 단어를 그릴 때는 파일명에 뜻을 붙인다: `ip-leaf.svg`, `bae-pear.svg`, `nun-snow.svg`, `cha-car.svg`.

## 그림이 안 될 때 — 글로 대체
사용자가 검수 페이지에서 "이건 못 알아보겠다"고 짚은 단어는:
1. 한 번 더 그려서 고칠 수 있으면 고친다(배치 3처럼 규칙을 바꿔서).
2. 두 번째도 안 되면 **그림 자리를 접고 큰 글자 + 예문**으로 간다(동사·B1+ 추상어와 같은 대우). 억지로 세 번째를 그리지 않는다.
manifest.json에 없는 단어 = 그림 없음 = 카드가 자동으로 글자 모드로 뜨는 게 UI 쪽 규칙(어휘 카드 붙일 때 반영).

## 그림 대신 텍스트 배지로 가는 경우 (2026-09-07 확정)
"관계로만 구분되는 단어"는 그림을 그리지 않는다 — 다른 단어 앱(Rosetta Stone·Drops·Duolingo)도 사회적 관계어에는 그림을 안 쓴다는 게 확인됨(사물에만 씀).
- **기준: 두 단어가 같은 사람/사물을 가리키는데 화자 쪽 조건만 다르면** 그림으로 못 가른다. 예: 형/오빠(화자 성별), 누나/언니(화자 성별), 이모/고모(친가·외가), 사촌(성별 미정).
- 이런 단어는 `manifest.json`에 넣지 않는다. 대신 `text-badges.json`에 `{ "단어": { "note": "한 줄 설명", "hint": "왜 그림이 안 되는지/구분법" } }` 형식으로 넣는다.
- 카드 UI 쪽 규칙: manifest에 그림이 없으면 카드는 그림 자리에 note를 큰 글자로, hint를 작은 글자로 보여준다(동사·B1+ 추상어의 "글자 모드"와 같은 컴포넌트를 재사용).
- 반대로 나이·성별처럼 **눈에 보이는 속성**으로 갈리는 단어(할아버지/할머니, 아들/딸, 남동생/여동생, 아기/아이/어른)는 계속 그림으로 간다 — 이건 그림으로 못 가르는 게 아니라 실제로 다르게 생겼다.
